# 🧮 Responsive Calculator (HTML, CSS, JavaScript)

This project is a **responsive calculator web application** built using **HTML, CSS, and JavaScript**.  
It performs basic arithmetic operations while maintaining a clean, modern, and user-friendly interface.

The goal of this project was to practice JavaScript logic, event handling, and responsive UI design.

---

## 🚀 Project Overview

The calculator allows users to:
- Perform basic mathematical operations
- Clear or delete inputs
- View results instantly
- Use the calculator seamlessly across devices

This project focuses on combining functionality with an engaging UI.

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & responsiveness
- **JavaScript (Vanilla JS)** – Calculation logic

---

## ✨ Features

- Basic arithmetic operations (+, -, ×, ÷)
- Percentage calculation
- Clear (AC) and Delete (DEL) functionality
- Responsive layout
- Clean and modern UI
- Real-time input display

---

## 🧠 Concepts Used

- DOM manipulation
- Event listeners
- Input handling
- Conditional logic
- UI state updates
